# Contract v0.2.0

**Trigger:** intent must be compiled into autonomous, stateful, verifiable execution.

**Minimum input:** purpose; desired state; accountable human; evidence of success; constraints; authority or grantor; key assumptions/unknowns.

**Required output:** schema-compatible `MissionSpec`; referenced `AuthorityGrant`; state transitions; evidence obligations; exception/recompile conditions; reality and disconfirmation tests.

**Validity test:** a Mission is not a task list. It requires a desired state transition, consequence owner, evidence, authority, constraints and termination/recompile logic.

**Route:** authority unresolved → `human-sovereignty-machine-agency`; weak evidence/feedback → `reality-loop-organizational-learning`; strategic premise unresolved → `vision-driven-strategy`.

**Eval:** must be executable without continuous human routing while remaining bounded and falsifiable.
