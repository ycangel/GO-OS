# Contract v0.2.0

**Trigger:** slow feedback, stale/contradictory evidence, repeated mistakes, escalation loops, weak memory, or low learning rate is primary.

**Minimum input:** action→observation→decision loop; evidence sources; latency; recurring exceptions; how learning is retained/reused.

**Required output:** loop map; latency/fidelity diagnosis; EvidenceSpec examples where useful; recurrence pattern; structural learning target; memory/capability update; disconfirming evidence.

**Invariants:** metrics are representations, not reality; faster loops are not better if they amplify noise; recurring exceptions require structural treatment; memory remains versioned and challengeable.

**Route:** structural cause → `ai-native-organization-design`; strategic belief update → `vision-driven-strategy`; mission redesign → `mission-organizational-runtime`.

**Eval:** must improve evidence-correcting convergence, not merely increase reporting or iteration frequency.
