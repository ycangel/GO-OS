# Intelligent Compounding & AI-Native Business v0.2.1

## Purpose
Determine whether AI creates a structural compounding advantage and redesign the business so usage, evidence, intelligence, customer value and organizational capability reinforce one another.

## Core distinction
**AI-enhanced:** AI lowers cost or improves a feature, but transactions do not materially strengthen the system.
**AI-native compounding:** meaningful cycles generate evidence, capability, economic or network value that improves future cycles.

## Loop library
- Data: `usage → proprietary evidence → better understanding → better outcome → more usage`
- Capability: `execution → exception → learning → reusable capability → better execution`
- Customer: `better fit → better result → trust/retention → richer interaction → better fit`
- Distribution: `better product → lower acquisition friction → more users → more learning → better product`
- Network: `more participants → richer interactions → better coordination → more value → more participants`
- Economics: `intelligence → lower marginal cost / higher quality → broader viable demand → more usage → more learning`

## Procedure
Map current value creation; identify AI insertion points; test whether use creates unique evidence retained as improvement; find broken links; design proprietary learning around interaction/outcome/exception data; connect internal learning to customer value/economics; test commoditization, trust, regulatory and runaway-error risks.

## Decision rules
Do not call a business AI-native merely because AI is central. Proprietary evidence quality matters more than generic data volume. If competitors can buy the same model and achieve the same result, the moat is elsewhere. Strong businesses compound customer value and capability, not only automation savings.

## Output contract
Return AI-enhanced vs AI-native judgment; loop map; reinforcing/broken loops; proprietary evidence opportunities; capability/economics loops; moat durability; commoditization risks; next experiments and disconfirming evidence.
