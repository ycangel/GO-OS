# Contract v0.2.0

**Trigger:** the primary question concerns AI-native economics, moat, flywheels, data/capability loops, personalization, network effects, or whether learning compounds.

**Minimum input:** stakeholder value; loop inputs/outputs; customer behavior; data/capability effects; costs and unit economics where available.

**Required output:** compounding-loop map; causal mechanism; bottleneck/leakage; stakeholder-value test; economic test; evidence required; disconfirming evidence; next experiment.

**Invariants:** more data is not automatically a moat; more intelligence is not automatically more value; a loop must improve the next cycle and connect to valuable outcomes/economics.

**Route:** organizational learning bottleneck → `reality-loop-organizational-learning`; strategic choice → `vision-driven-strategy`; structural bottleneck → `ai-native-organization-design`.

**Eval:** must distinguish AI-enhanced efficiency from genuinely self-reinforcing AI-native value creation.
