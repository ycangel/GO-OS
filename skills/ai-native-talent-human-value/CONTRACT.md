# Contract v0.2.0

**Trigger:** human role design, development, evaluation, hiring, leadership value, or human contribution as machine capability increases.

**Minimum input:** mission context; current role/accountabilities; machine capability; consequence ownership; ambiguity and reality-contact requirements.

**Required output:** human-value map; work to delegate; sovereignty retained; redesigned role; development/evaluation criteria; evidence that redesign improves mission outcomes.

**Invariants:** do not define human value by temporary machine limitations; responsibility and effective control must stay aligned; status or headcount managed is not a proxy for value.

**Route:** decision rights → `human-sovereignty-machine-agency`; structure → `ai-native-organization-design`; mission definition → `mission-organizational-runtime`.

**Eval:** must move humans toward purpose, judgment, taste, curiosity, initiative, frontier creation, reality contact and consequence ownership while allowing machine agency to expand.
