# AI-Native Talent & Human Value v0.2.1

## Purpose
Redefine roles, talent standards and performance around human sovereignty, mission ownership and intelligence leverage rather than task volume or headcount management.

## Core thesis
Human value should not be defined by temporary machine limits. Anchor durable human value in purpose formation, responsibility, value arbitration, taste/judgment, curiosity, initiative, reality contact, frontier creation, trust stewardship and ownership of consequences.

## Required inputs
Mission/role context; current tasks; machine capabilities; consequence ownership; ambiguity; contact with reality/customers; current performance metrics.

## Procedure
1. Decompose routine cognition, coordination, execution, judgment, relationship work, purpose, accountability and frontier exploration.
2. Move repeatable, verifiable, bounded cognition/coordination to machines where feasible.
3. Preserve explicit human sovereignty over purpose, important tradeoffs, irreversible consequences, contested values and accountability.
4. Increase intelligence leverage: let capable people direct more machine intelligence/tools/capabilities.
5. Replace static job descriptions with mission, authority, evidence, judgment, capability and exception portfolios.
6. Evaluate mission outcomes, judgment quality, learning rate, capability creation, responsible AI leverage, evidence quality, recurring-exception reduction, memory contribution, trust and consequence ownership—not visible busyness or team size.
7. Shift leadership from supervising execution toward direction, system design, authority, capability, reality interpretation, value conflicts and organizational learning rate.

## Output contract
Return role decomposition; machine delegation; human sovereignty responsibilities; new mission portfolio; authority design; talent criteria; performance measures; capability-development priorities.
