# GO Cognitive Interface Adapter Specification v0.3.4

## Definition

A Cognitive Interface Adapter connects external AI interfaces or human interfaces to the Headless GO Core.

## Supported Interfaces

- ChatGPT Projects
- Claude
- DeepSeek Harness
- GO Web
- Voice Agents
- Physical AI Interfaces

## Responsibilities

Adapters translate interaction into GO OS organizational events:

- Cognitive Events
- Deliberation Sessions
- Evidence Updates
- Evolution Proposals

## Constraint

The interface is not the organization.

The interface is only an entry point into organizational intelligence.
