# GO OS v0.5.0 Public Narrative

## Release line

**GO OS v0.5.0 — Foundation Release / 奠基版本**

The English name is a software release-stage label. In Chinese it is always
rendered as **“奠基版本”**. It does not state or imply that a foundation or
other legal entity has been registered.

## Headline

> **Reinvent Organizations.**
> **Enable organizations to evolve themselves.**

## Foundational question

> **How does intelligence become part of an organization?**

GO OS answers by connecting human purpose, bounded machine agency and evidence
from reality in a recursive learning loop. The objective is not to add more
agents to an unchanged hierarchy. It is to make authority, cognition, action,
learning and controlled organizational change explicit and inspectable.

## Constitutional formula

> **Human Sovereignty × Machine Agency × Reality as Final Arbiter**

- Humans retain purpose, value judgment and responsibility for irreversible
  consequences.
- Machines may plan, act and propose changes only inside explicit, revocable
  authority.
- Reality can contradict leaders, agents, plans and organizational assumptions.

## The shift

```text
Relationship-driven organization
→ Hierarchy-driven organization
→ Evolution-driven organization
```

This is a proposed organizational paradigm, not a claim that hierarchy is
obsolete or that GO OS has already proven superiority.

## The v0.5 baseline

The release freezes eight reference-runtime objects:

`Mission · AuthorityGrant · Evidence · CognitiveEvent · DeliberationSession · LearningRecord · EvolutionProposal · CognitiveVersion`

It also publishes a headless architecture, machine-readable contracts, Skills,
declared evaluations, Cognitive Repository specifications and an alpha GO
Society Web reference surface.

## Required maturity language

Use these labels in public communication:

- **implemented** for inspectable code paths;
- **specified** for a design or contract;
- **declared evaluation** for a test vector without an execution result;
- **demonstrated** for a bounded example;
- **field-validated** only with real operating evidence and limitations;
- **planned** for roadmap work.

Do not turn “GO OS runs on GO OS” into proof. It is a self-application and
falsification strategy until operating history demonstrates the full loop.

## What v0.5 does not say

- AI should autonomously govern organizations.
- More agents automatically create an AI-native organization.
- Chat history is organizational memory.
- A successful build or live site proves organizational outcomes.
- All eight objects are production-complete.
- GO Society or GO Foundation is a registered legal entity.
- Gödel's mathematical theorems prove the GO OS organizational thesis.

The durable public promise is narrower and stronger:

> GO OS will remain open to evidence that changes GO OS.
