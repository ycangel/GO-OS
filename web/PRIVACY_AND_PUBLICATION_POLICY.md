# GO Society 企业反馈与公开案例隐私与发布政策

> **Private by default. Public by consent, de-identification, and human accountability.**  
> 默认私有；经脱敏、授权与具名人类审批后方可公开。

版本：0.1  
适用范围：GO Society 网站、GO OS 仓库、案例库，以及由相关资料生成的博客、播客、图片、动画和社交媒体内容。

## 1. 基本原则

1. **默认私有**：所有新收集的企业反馈均以私有状态进入系统，未经审核不得公开。
2. **最少收集**：只收集完成任务所必需的信息；能不记录姓名、联系方式、精确公司信息和原始录音，就不记录。
3. **身份与内容分离**：真实身份、联系方式及别名映射与反馈内容分开保存，并采用最小权限访问。
4. **别名优先**：企业、决策者、管理咨询师及其他参与者默认使用别名、角色类别或概括描述。
5. **人类负责**：Agent 可以辅助检查和整理，但无权独立批准公开发布。
6. **不确定即私有**：无法确认是否存在重新识别风险时，按“可识别”处理并保持私有。

## 2. 三层数据边界

| 数据层 | 用途 | 访问范围 | 公开规则 |
|---|---|---|---|
| 私有原始记录 | 访谈笔记与必要上下文 | 经授权的任务成员 | 永不直接公开 |
| 脱敏证据 | 去除身份信息后的观察与假设 | 经授权的成员与审核者 | 通过发布审核后才可公开 |
| 公开案例 | 经验证、脱敏和批准的独立发布物 | 公众 | 仅展示必要且安全的信息 |

公开案例必须标注其证据阶段：`Signal`、`Probe` 或 `Validated Case`。单次访谈或未经验证的反馈不得表述为已验证案例。

## 3. 不得公开的信息

除非获得明确、可追溯的授权，否则以下信息不得出现在公开页面、仓库、API、日志或衍生内容中：

- 企业、决策者、员工或管理咨询师的真实姓名；
- 邮箱、电话、社交账号、地址及其他联系方式；
- 原始录音、录像、逐字稿、会议截图和内部文件；
- 能直接确认企业身份的客户名、项目名、产品代号或组织结构；
- 未经授权的逐字引用；
- 可能造成重新识别的精确日期、地点、金额、岗位、客户数量或罕见特征组合；
- 商业秘密、未公开经营数据及受保密义务约束的信息。

必要数字优先采用区间、比例或聚合表达。公开引语默认改写为不改变原意的概述；使用逐字引语必须取得明确许可。

## 4. 收集与告知

收集反馈前，应向参与者说明收集目的、私有范围、脱敏与汇总方式、授权选项，以及更正、撤回和删除方式。匿名参与、匿名分析、匿名公开与具名公开是不同授权，不得合并推定。

不得以宣传压力换取反馈，也不得将拒绝公开理解为拒绝参与。

## 5. 脱敏要求

公开前至少完成以下处理：

- 删除姓名、公司名、联系方式及直接身份标识；
- 将精确职位转换为角色类别；
- 将企业转换为不可反向推断的别名或概括描述；
- 对日期、地点、规模、金额及其他准身份信息进行泛化；
- 检查多项信息组合后是否仍可推断个人或企业身份；
- 清除附件、文件元数据、图片信息及隐藏字段中的身份信息。

企业别名与真实身份的映射必须保存在私有区域，不得进入公开仓库或公开接口。

## 6. 公开发布门槛

任何企业反馈、案例或衍生内容公开前，必须同时满足：

1. 内容与 GO Society 的公共使命直接相关；
2. 已完成 Agent 辅助的个人信息与敏感信息扫描；
3. 已完成重新识别风险检查；
4. 已由一名具名且有权限的人类审核者批准；
5. 已取得明确、可追溯的匿名发布同意；
6. 已记录来源、处理过程、审核者、同意状态和发布时间；
7. 公开版本不包含原始记录或身份映射。

高风险、争议性或涉及敏感经营数据的内容应进行第二人复核。Agent 的检查结果仅作为辅助证据，不能替代人类判断。

## 7. 来源、审计与权限

每条公开证据应保留内部审计链：私有来源记录 ID、收集者、转换过程、检查结果、审核者、同意状态、时间、版本、更正与撤回。公开页面只能展示不会造成身份泄露的来源类别与证据状态。

成员只获得完成其 Mission 所必需的最小权限。退出任务或组织后应及时撤销访问。记录权限不自动包含审核、发布或访问其他 Mission 的权限。

## 8. 更正、撤回与下架

参与者可以要求更正不准确的信息、撤回尚未发布的反馈、撤销未来使用授权，或对存在识别与伤害风险的公开内容提出下架。收到合理请求后，应先暂停传播，再完成核查、修订或下架；审计记录本身不得继续暴露被撤回的信息。

## 9. 发布检查清单

- [ ] 原始记录保持私有；
- [ ] 企业与个人均已使用安全别名或概括描述；
- [ ] 不含姓名、联系方式、原始录音、逐字稿或内部文件；
- [ ] 已处理精确日期、地点、金额及其他重新识别线索；
- [ ] 已完成 Agent 辅助的 PII 与重新识别检查；
- [ ] 已由具名人类审核者批准；
- [ ] 已取得匿名发布同意；
- [ ] 已建立来源、审批、版本与撤回记录；
- [ ] 博客、播客、图片、动画等衍生内容同样通过本检查。

任何成员或 Agent 均不得以传播效率、案例价值或技术便利为理由绕过本政策。
